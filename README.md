# 👨‍🍳 Chefim

> **Seu companheiro na cozinha**

## 🎯 Objetivo do App

O **Chefim** é um aplicativo que auxilia o usuário no gerenciamento dos alimentos de sua despensa, permitindo controlar produtos, quantidades e datas de validade.

O aplicativo também sugere receitas com base nos ingredientes disponíveis e permite definir a quantidade de pessoas para a qual a receita será preparada, identificando os ingredientes que estão disponíveis e os que estão faltando.

O objetivo é facilitar o planejamento das refeições, promover uma alimentação mais consciente e **reduzir o desperdício de alimentos**, incentivando o consumo dos produtos antes que atinjam a data de validade.

---

## 🚀 Principais Funcionalidades

### 🟢 Funcionalidades do MVP

* **Cadastro de produtos:** permitir o registro dos alimentos, incluindo quantidade e data de validade.
* **Leitura de código de barras:** facilitar o cadastro dos produtos por meio da leitura de seus códigos de barras.
* **Controle de validade:** acompanhar as datas de validade dos produtos cadastrados.
* **Controle de estoque:** permitir a visualização dos alimentos disponíveis e suas respectivas quantidades.
* **Sugestão de receitas:** recomendar receitas de acordo com os ingredientes disponíveis, priorizando produtos próximos do vencimento.
* **Definição de quantidade:** permitir que o usuário informe para quantas pessoas deseja preparar uma receita.
* **Cálculo dos ingredientes:** ajustar automaticamente as quantidades dos ingredientes de acordo com o número de pessoas informado.
* **Identificação de ingredientes faltantes:** comparar os ingredientes necessários com os produtos disponíveis no estoque.

### 🔵 Funcionalidades Planejadas

* **Informações nutricionais:** apresentar informações nutricionais dos produtos cadastrados, como calorias, proteínas, carboidratos e gorduras, quando disponíveis.
* **Estimativa calórica:** calcular uma estimativa das calorias da receita e apresentar o valor por porção.
* **Lista de compras:** permitir que os ingredientes faltantes sejam adicionados a uma lista de compras.
* **Notificações:** alertar o usuário quando um produto estiver próximo da validade.
